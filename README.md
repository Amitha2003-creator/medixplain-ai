# MediXplain AI

Educational assistant that explains medical reports in simple English or Malayalam.
It does not diagnose, prescribe, or replace a doctor.

**Demo only: please use fictional reports, not real patient data.**

Features: report upload and lab-value checks, AI explanations, doctor questions,
specialist guidance, report comparison and trends, Ask My Report chatbot with
MedlinePlus sources, voice questions, PDF summaries, and patient / doctor / admin roles.

Medical information in the knowledge base is courtesy of MedlinePlus from the
National Library of Medicine.
